## 1. 维护口径

状态统一使用：`待处理`、`进行中`、`代码完成`、`自动验证`、`宿主已验收`、`阻塞`、`取消`。

- 同一事项只保留一个稳定 ID；状态变化直接更新原行，并在“变更记录”追加结果。
- “代码完成”不等于产品可交付；页面、编辑器、焦点、滚动、快捷键、真实性能和外部 Provider 必须经过真实 Tauri 宿主验收。
- 问题关闭时保留根因、修复证据和关闭日期，不删除记录。
- 新需求先进入 PRD 判断范围和优先级，再进入本台账排期；技术设计变化同步更新架构文档。
- 不再创建 `TODO.md`、`PROJECT-STATUS.md`、`PROGRESS.md` 或新的日期审计文档。

## 2. 当前结论

SophoNote 已具备本地 Markdown 笔记、知识组织、信息采集、证据化 AI、Inline Completion、AI 工作室、Hermes Agent Runtime、Skill、MCP 和安全文档 Patch 的主要代码能力。DEC-027/028 已将旧 Library 页面下线：当前一级导航展示**发现、会话、工作室、笔记本、计划任务、工具**；收件箱保留在原“设置 → 收件箱”，旧知识库的信息条目检索/索引能力归并其中，并以首次拉取起 168 小时为严格 TTL。DEC-030 进一步明确：知识层隐藏并负责检索/版本/证据/关系，记忆层属于 Hermes Agent，未来 Artifacts 只投影项目/笔记/记忆摘要/成果。当前阶段七条主线：

1. **P0 写作性能**：页签/文档/输入/预览宿主验收收口。
2. **P1 宿主与发布 Go**：Agent/文档修改整场验收、真实 Provider/MCP、发布安全。
3. **P1 战略 · Hermes Client Surface（DEC-011 / DEC-012 / DEC-013 / DEC-019 / DEC-020）**：产品 Agent 已收敛为 Hermes-only，并复用 Hermes Session、Skill、Memory、工具状态机和完整事件。Hermes 0.20.0 + CPython 已钉扎随 macOS `.app`，Release 不再读取机器 Runtime；逐文件 hash、私有 Home、生命周期、Keychain、CSP、updater 与签名/公证脚本已完成，本机隔离冒烟通过。Developer ID 公证与独立干净 macOS VM 的 D4/D5 证据仍属 NEXT-009 外部门禁。Windows NSIS 打包流水线见 NEXT-070 / DEC-049，真实 Windows 宿主验收未完成。
4. **P1A 新版会话与产品壳（DEC-015～018）**：抽取共享会话内核、一级会话页、六域导航、工作室/笔记本嵌入面板、ContextHandoff、会话内运行状态、ScopeSnapshot 和会话归属项目；先复用现有 Hermes/RunStore 能力，再开放跨域副作用工具。
5. **P1C 轻量知识版本与证据（DEC-024/025/026）**：先落 ResourceBudgetManager、Hot/Warm/Cold、跨进程 1 GiB Memory Envelope、共享 lease 与 FTS-only 降级，再以 managed notes bare repo + 授权项目 Git 仓库建语义版本。向量只覆盖磁盘粗召回后的候选/当前工作集；P2 再扩展 Claim/Decision、ChangeImpact 与 Hermes Memory 证据绑定。
6. **P1D Browser 与代码工作闭环（DEC-031）**：先落 WorkspaceBinding/权限模式，再将 `browser.manage` 扩展为会话、工作室、笔记本可见 Browser；会话/工作室补文件树、代码编辑、Git Diff、Terminal、Preview 和 Agent 验证。首版对齐 Claude Code 核心闭环，不做完整 IDE、worktree/PR 或默认 push。
7. **P0 开源准备 + Hermes Desktop 基础完整度（DEC-048 / DEC-052）**：许可证/NOTICE/贡献说明、独立 GitHub remote 与密钥/路径扫描已落盘；发布前继续收口个人运行数据隔离、可复现打包与宿主门禁。会话面已补上下文占用、Composer 历史、会话内查找、`/undo`、本轮 YOLO，以及 chat tab 的 Tauri 原生拖放路径；宿主对照 `/` `@` 与附件真实 Run 仍待走查。不克隆 Bot Mode / HUD / 语音 / Memory Graph。coding 域继续冻结。

产品不建设飞书式逐次 autosave 历史；编辑器 `⌘Z`、内部并发 version、operation 审计和有界 AI checkpoint 继续独立存在。正式知识另建 Git 语义版本与结构化变更依据，异步执行且恢复仍经 DocumentService Patch。
