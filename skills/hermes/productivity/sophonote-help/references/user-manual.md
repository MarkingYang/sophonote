# SophoNote 使用手册

本手册是 SophoNote 使用方式的说明源。界面只保留操作、状态与必要风险确认；使用方法和问题排查由智能体按需回答。产品界面为中文，本手册正文与界面一致。社区入口见仓库根 `README.md`（English）与 `README.zh-CN.md`（简体中文）。

## 1. 产品入口

- **发现**：查看经过筛选和解读的 AI 动态、报告与模型榜。
- **会话**：以任务为单位使用 Agent；可临时绑定本地目录。
- **工作室**：面向本地项目的 IDE 工作区，包含文件、搜索、变更、终端、浏览器与右侧 Agent。
- **笔记本**：编辑 Markdown 笔记，并让 Agent 读取或修改当前文档、选区。
- **计划任务**：管理 Hermes 定时任务、运行状态和历史结果。
- **工具**：查看今日事项、任务与番茄钟。
- **设置**：管理模型、数据源、收件箱和 Agent 能力。

## 2. 会话

新建会话后直接描述任务。通过输入框左下角 **+** 可加入文件、文件夹、图片、URL 或选择 Skill。输入框上方的芯片表示当前工作范围；移除芯片会取消后续轮次对该范围的访问，不会删除本地文件。

绑定本地目录后，会话可读取该目录及子目录。关闭会话只结束会话入口，不删除目录。项目会话保留在项目中；同一会话不会同时重复显示在多个列表分组。

## 3. 会话权限

权限入口位于输入框左下角 **+** 后方。

- **询问权限**：修改文件、执行命令或产生外部影响前确认。
- **自动编辑**：文件修改可自动接受；命令和敏感操作仍需确认。
- **计划模式**：只读取、分析和提出方案，不写文件、不执行命令。

权限属于当前会话。工作室状态栏只显示当前模式，不能从状态栏修改。切换模式不扩大已绑定的目录范围。

## 4. 工作室

工作室绑定真实本地文件夹或 Git 仓库，原目录是代码和 Markdown 的真相源。

- Activity Bar 依次提供 Explorer、Search、Source Control、Terminal、Browser 等视图。
- Explorer 打开文件；编辑器标签可同时维护多个文件。
- Source Control 查看 Git 状态与 Diff。
- Terminal 在项目目录中运行命令；支持命令历史、清屏、退出码与耗时，计划模式下不可执行。
- Browser 位于 Terminal 下方，可打开网页、localhost 和本地文件。
- 右侧 Agent 负责理解任务、提出修改、执行受控命令并验证结果。

SophoNote 不再维护独立的“项目文档”副本。本地项目中的 `.md` 文件就是项目文档，可直接编辑并由 Git 管理。

## 5. 笔记本

笔记使用 Markdown。打开笔记后可直接编辑、预览或让 Agent 处理当前文档。选中文本后发起任务时，范围只限选区；未选中文本时使用当前文档范围。写作命令、审阅落盘与标题确认见仓库 `docs/sophonote-markdown-writing.md`。

Agent 修改会形成可审阅变更。接受后写入原文，拒绝则保留原文。若右侧只返回文字、左侧没有变更，表示本轮没有提交可应用的文档修改。

进入笔记本、切换日期或回到今天都只读取已有笔记，不会自动创建文档。空态可选择“新建第一篇笔记”，也可显式导入 6 篇功能范例；“新建笔记”右侧菜单始终可以再次补齐缺失范例。同名笔记不会被覆盖。范例覆盖 Markdown、大纲、任务、双链/反链/嵌入、搜索与模板，导入后与普通笔记相同，可自由编辑或删除。

## 6. 浏览器与本地文件

会话、工作室和笔记本共用浏览器能力。地址栏支持普通网页、PDF URL 和 `localhost`。本地文件不使用单独的 PDF 按钮：把文件拖入 Browser，或在工作室项目树中点击具体文件。

- PDF 和图片在 Browser 中打开；PDF 使用系统原生阅读能力。
- 支持 `jpg/png/gif/webp/svg` 图片和 `txt/md/json/xml/csv` 文本拖入查看。
- 项目树中的 Markdown、JSON 等文本点击后进入源码编辑；PDF 和图片点击后切到 Browser。
- 只有用户拖入的文件或当前项目授权范围内的具体文件会被开放给 Browser。

网页无法打开时依次检查：地址是否完整、网络是否可用、站点是否拒绝桌面 WebView、localhost 服务是否已启动。Agent Browser 未连接时，普通可见浏览仍可用，但 Agent 的点击、输入、截图和页面检查不可用。

## 7. 模型配置与选择

在 **设置 → AI 模型** 添加供应商、保存凭据并配置模型。会话模型菜单只显示同时满足以下条件的模型：

1. 供应商存在于设置；
2. 凭据已保存；
3. 模型位于设置的模型清单；
4. Hermes Runtime 当前可执行。

仅被 Runtime 或外部环境发现、但未在设置中配置的模型不会显示。模型缺失时先检查供应商凭据和模型清单，再重新打开会话。

Runtime 已发现但尚未配置的模型位于 **设置 → AI 模型 → Runtime 发现**。选择供应商后可搜索、多选并加入配置；新供应商还需要补充接口地址和凭据。只有完成配置且 Runtime 可执行的模型才会进入会话和计划任务。

## 8. 计划任务

计划任务以 Hermes Cron 为唯一执行来源。可创建、编辑、启停、立即运行和查看历史。项目和模型属于任务的运行设置。暂停任务不会删除历史；删除任务会移除该计划定义。

“使用范例”提供 5 个脱敏任务模板。选中范例只会打开预填表单，保存后也始终保持暂停；它不会携带维护者的模型、任务 ID 或运行历史。为任务选择可用模型并保存后，可以点击“立即运行”单次执行；只有手动启用，Hermes 才会按计划周期触发。

日报、发现解读等时间统一在计划任务中管理，设置页不保留第二套触发时间。

## 9. 收件箱与知识沉淀

收件箱位于设置中，保存数据源拉取的短期信息。条目从首次拉取时刻起保留 168 小时；刷新、阅读、收藏或归档都不会延长时间。过期后清理短期条目与对应缓存。

需要长期保留的内容应沉淀为项目文件、Markdown 笔记或明确的 Agent 记忆。知识层不提供独立页面，不把收件箱列表当作长期记忆。

## 10. Skill、Tools 与 MCP

Skill、Tools、MCP 和 Browse Hub 位于设置的能力卡片中。会话输入框 **+ → 技能** 用于选择本轮 Skill。

- **Skill**：为 Agent 提供特定任务规则和知识。
- **Tools**：Agent 可调用的执行能力。
- **MCP**：连接外部或本地工具服务。
- **Browse Hub**：浏览和安装可用 Skill。

能力未启用、连接失败或不在当前会话权限范围内时，Agent 不应宣称可以调用。

## 11. 常见问题

### 模型菜单出现“未配置模型”

前往 **设置 → AI 模型**，确认供应商凭据已保存，模型在该供应商清单中，并等待 Runtime 恢复连接。

### Agent 无法修改文件

确认会话已绑定正确目录，权限不是计划模式，目标文件位于授权目录内，并处理当前等待中的审批。

### 终端无法执行

计划模式禁止命令。切换到询问权限或自动编辑，并确认工作室已绑定本地目录。

终端使用 ↑/↓ 选择历史命令，⌘K 或顶部清空按钮清屏。当前版本的长驻服务仍建议交给 Agent 作为受控后台进程启动。

### 浏览器能看网页但 Agent 不能操作

连接 Agent Browser。连接前可见浏览器只供用户查看，不提供 Agent 页面控制与检查。

### 笔记没有出现修改

确认输入框上方有当前文档或选区芯片，并明确要求修改而不是只给建议。只有真实文件差异才会出现审阅入口。

### 会话中找不到某个 Skill

在设置的 Skill 卡片中确认已安装并启用，然后重新打开 **+ → 技能**。Runtime 未返回的 Skill 不会显示。

### 定时任务没有运行

检查任务是否启用、下一次运行时间、模型是否仍可用，以及最近一次运行结果。模型或凭据失效时先修复模型配置。
