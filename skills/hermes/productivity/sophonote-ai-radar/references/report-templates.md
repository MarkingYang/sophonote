# 报告结构（日 / 周 / 月）

> 融合自 ai-radar v1 `templates/daily_report.md` 与 aihot dailies 结构（lead / sections / flashes）。
> 报告是**固定周期日切成品**：不是滚动窗口的别名，不得把「最近 7 天查询」称为周报。

## 通用骨架

```markdown
# {期号标题}

{lead：3-5 句开场综述，本期最重要的 1-3 个主题}

## 一、{主题小节标题}

1. [{条目标题}]({原文链接})
   - {来源} · {北京时间}
   - {一到两句中文摘要}
   - {入选理由，仅在证据足以支持时写}

## 二、{...}

## 快讯

- {标题}（{来源}）
- {标题}（{来源}）

---
本期 {N} 条 · 精选 {M} 条 · 覆盖信源 {K} · 涉及主题 {T}
_由 SophoNote AI 雷达生成 · 评分口径：时效 20 / 影响 30 / 深度 20 / 可操作 15 / 权威 15_
```

## 期号规则

- 日报：`AI 日报 · YYYY-MM-DD`（window = 指定日，默认当天）
- 周报：`AI 周报 · YYYY-'W'ISO周号`（window = 指定日所在自然周，周一至周日）
- 月报：`AI 月报 · YYYY-MM`（window = 所在自然月）

## 小节规则

1. `sections` 的主题取自本期高分条目（≥8.5 优先）的 `ai_topics` 聚集；一节 = 一个主题焦点，2-6 条。
2. 未成节但 ≥7 分的条目全部进「快讯」一行流，不丢弃。
3. 保持 lead / sections / flashes 的结构与顺序，不重排成普通条目列表。
4. 小节用中文数字编号（一、二、三…），标题不跳级（Markdown 纪律）。

## 周期增量

- 周报：lead 之后加「本周焦点」三问——发生了什么 / 为什么重要 / 接下来看什么。
- 月报：加趋势叙事段与模型榜变化（名次升降、新上榜），引用模型榜快照数据。

## 纪律

- 数据只来自 `read_discovery_feed` 返回的已存打分与分析；不抓网、不重复打分、不用训练记忆补新闻。
- 不发明事实；缺失写「未披露」；链接与引文原样保留。
- 时间展示统一 `Asia/Shanghai`；`publishedAt` 缺失时标注「收录时间」。
