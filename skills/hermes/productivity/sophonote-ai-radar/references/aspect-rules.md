# Aspect 规则（精选五面）

> 「精选」断面的分面枚举与判定规则。aspect 在打分同趟输出，可为 null（null 条目不进精选，仍可进全部 AI 动态与主题）。

## 枚举（仅五值）

| aspect | 判定 | 对应「内容形态」主题 |
| --- | --- | --- |
| `模型` | 模型发布、权重/榜单变动、模型卡与评测表现 | 模型发布、评测基准（模型相关） |
| `产品` | 产品发布与功能更新、开发者工具、应用落地 | 产品更新 |
| `行业` | 行业动态、政策监管、融资并购、市场格局 | 行业动态、政策监管、现象与趋势（行业向） |
| `论文` | 论文研究、方法创新、数据集与基准论文 | 论文研究 |
| `观点` | 人物观点、评论、趋势研判、教程实践中的观点性内容 | 大佬观点、现象与趋势（观点向）、教程实践 |

## 规则

1. 每条至多 1 个 aspect；边界模糊时按「条目主要价值是什么」取一面，不强行归类则 null。
2. 纯教程/操作指南若无观点增量 → aspect=null（进全部与主题，不进精选）。
3. 精选门槛 = `aspect 非空 ∧ 近 7 天打分 ∧ score ≥ 8.5`。
4. aihot 数据互操作提示：其 category `ai-models→模型`、`ai-products→产品`、`industry→行业`、`paper→论文`、`tip→观点`（仅作提示，最终以本表判定为准）。
