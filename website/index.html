## 产品判断

首要差异不在于模型数量，而在于

− 是否提供更多自动化能力。

+ 是否形成可控、可恢复、可验证的工作闭环。

这一判断引用了 [E1] 架构说明 与 [E2] 实际运行记录。

1 个区域待审阅拒绝接受
书写与审阅

让 AI 靠近正文，但不让它越过你。

Markdown 是正文真相源。AI 修改绑定版本、选区与文本锚点，以逐区域 Diff 呈现；冲突时停止，不猜测覆盖。

  • 编辑、预览与分屏围绕连续书写设计
  • 一次 AI operation 对应一个撤销步骤
  • 保存失败保留草稿，不把失败说成成功
项目与任务

一个本地目录，
一项持续推进的工作。

选择本地文件夹建立项目。围绕项目创建任务，在多轮对话中补充要求，随时浏览文件并把所需资料加入当前任务。

  • 项目首页搜索与排序，快速回到手头工作
  • 每个项目独立组织任务，保留历史与置顶
  • 文件按需读取，成果留在真实本地目录

03 / 产品原则

先进能力，
必须配得上清晰边界。

SophoNote 不把“自动化更多”当作唯一目标。真正可信的本地 AI 工具，要让用户始终知道数据在哪里、Agent 看到了什么、修改为什么发生。

阅读技术架构 ↗
01

本地真相源

笔记正文是你能直接读、直接导出的 Markdown；SQLite 只承担元数据、索引、运行与审计。

02

作用域透明

页面不是权限。每一轮只读取显式附件、选择范围与已授权工具，发送后冻结，不随导航悄悄扩大。

03

副作用可审

文档修改先展示 Diff；工具默认拒绝；高风险动作逐次确认。Skill 本身从不等于权限。

04

失败诚实

保存、模型、工具或 Runtime 失败都会留在原位置，保留可恢复状态，不用假步骤或成功文案掩盖。

04 / 开源

你不需要把知识押给一家公司。

SophoNote 以 MIT License 开源。客户端不设云端账号，仓库只维护源码、文档与脱敏范例；模型服务由你选择，相关 API 费用由对应供应商收取。

06 / 常见问题

先把关键问题说清楚。

我的数据真的都在本地吗？

笔记正文、索引、会话映射和应用状态保存在你的 Mac。启用 OpenViking 云端记忆、调用外部模型、抓取来源或你授权的 MCP 时，完成任务所需的最小上下文会发送给对应第三方；SophoNote 自身不提供云端账号或正文遥测。详见隐私说明。

如何切换 Hermes、Pi、Claude Code 和 OpenCode？

在会话输入框下方选择引擎。新会话首次发送后固定引擎；已有会话选择另一引擎时，会新建会话并保留未发送文字与附件，原会话历史仍可回看。历史不会跨引擎迁移。Hermes、Pi 与 OpenCode 随应用提供，Claude Code 需在本机安装官方 CLI。

四种引擎的能力完全相同吗？

四者共用模型配置、回复界面、文件审批与笔记修改审阅。Hermes 另外提供浏览器、电脑控制、计划任务及 Skill/MCP 管理；Pi、Claude Code 与 OpenCode 当前聚焦对话、文件与代码任务。四引擎可在确认后接入同一个 OpenViking 云端记忆库；能力配置支持按引擎筛选，可用工具会随所选引擎变化。计划任务目前由 Hermes 执行。

需要自己配置模型吗？

需要，在 AI 模型设置中配置一次即可。四种引擎共用供应商、密钥与模型选择，各自使用兼容的协议：Pi 支持 OpenAI 兼容和 Anthropic 配置；Claude Code 支持 Anthropic 协议及官方 DeepSeek 配置。已配置的 DeepSeek 无需另填密钥。本地或私有化 OpenAI 兼容端点可用于支持该协议的引擎；第三方模型费用由供应商收取。

在哪里更新 Agent 引擎？

进入「设置 → Agent 配置更新」，可统一查看四种引擎的版本与更新方式。OpenCode 随 SophoNote 版本更新。Hermes 更新后重启应用生效；Pi 更新后供后续运行使用；Claude Code 按本机安装方式调用官方更新器，不支持自动更新的安装会显示手动指引。更新保留模型配置和会话历史。

AI 会直接改掉我的笔记吗？

不会。AI 只能提出绑定版本、选区和文本锚点的修改提案；你接受后才写入笔记。版本或锚点冲突时系统停止，不做就近猜测替换。

现在支持哪些平台？

macOS 是完整体验和宿主验收平台，公开预览优先提供 Apple Silicon DMG。Windows x64 已有 CI 打包流程，但仍待真实 Windows 宿主验收与 Authenticode 签名；移动端和 Web 端不在当前范围。

SophoNote 与 Hermes Desktop 有什么关系？

SophoNote 是独立的知识工作台，可选择 Hermes、Pi 或本机 Claude Code 作为执行引擎，笔记、项目、审批和文档审阅由 SophoNote 管理。Hermes、Pi 与 OpenCode 为开源引擎；Claude Code 是可选的本机 CLI，不随应用分发。SophoNote 不是 Hermes Desktop 的分叉。
