05 / 常见问题

开始前，
你可能想知道。

免费吗？需要自己准备 API Key 吗？

SophoNote 客户端以 MIT 协议开源，不包含模型额度。你需要配置可用的模型服务；使用第三方模型时，费用由供应商收取。兼容的本地或私有模型端点可用于支持该协议的执行方式。

它和普通 AI 聊天工具有什么不同？

会话与本地项目、Markdown 笔记放在同一个工作台。你可以围绕文件与资料开展任务，查看处理过程，审阅笔记修改，再沿着项目继续工作。

需要先选择某一种 Agent 吗？

最新开发版会自动安排执行方式，你主要关注任务、进展与结果。公开预览包可能仍保留引擎选择，请查看版本说明。部分执行能力需要额外环境，例如 Claude Code 需要本机安装官方 CLI；可用能力取决于配置与授权。

我的资料会上传到哪里？

笔记正文和项目文件保存在本机。调用外部模型、抓取来源或使用你授权的工具时，完成任务所需的相关内容会发送给对应服务。可选云端记忆会把相关会话内容发送到你配置的 OpenViking 服务。SophoNote 自身不提供云端账号或正文遥测。详见隐私说明。

AI 会直接改掉我的笔记吗？

受管笔记先生成修改提案，你审阅并接受后才会写入。原文变化导致冲突时会停止，不猜测覆盖。项目文件和工具操作按照你授予的权限执行。

现在可以在哪些设备上使用？

公开预览优先提供 Apple Silicon（M 系列）Mac 安装包。Windows 仍待完整宿主验收，暂不承诺可用安装包；手机与浏览器版不在当前交付范围。
