更新于 2026 年 9 月 1 日

官网

SophoNote 官网是托管在 GitHub Pages 的静态站点，不提供账号系统，不设置分析 Cookie，也不在站内收集笔记正文或个人资料。页面会请求 GitHub Releases API，以找到仓库最新的公开 DMG；该请求受 GitHub 的隐私政策约束。

桌面应用中的本地数据

SophoNote 以本地 Markdown 文件作为正文真相源，并在本机保存索引、元数据、会话映射和运行记录。项目目录与应用数据不会因为访问官网而上传到 SophoNote 自有服务器。

外部模型、来源与 MCP

当你主动调用外部模型、抓取网络来源或运行已授权的 MCP 工具时，完成该任务所需的最小上下文会发送给对应第三方。具体处理方式、留存周期和地域由你选择的服务商决定。请勿向未获信任的服务提交敏感材料。

开源与问题反馈

你可以在 GitHub 仓库审查源代码。一般问题请使用 GitHub Issues；安全问题请按安全政策中的方式报告，避免公开披露漏洞细节。
