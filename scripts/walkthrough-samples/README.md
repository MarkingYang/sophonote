# 功能范例与开发走查笔记库（B4-B10）

这 6 篇 Markdown 同时服务两个场景：

- 普通用户在笔记本空态或“新建笔记”右侧菜单点击“导入功能范例”，经正式文档保存链路创建；应用不会自动播种。
- 开发者配合 `docs/PRD.md` §15 进行写作、知识组织与发布验收，降低构造数据的负担。

范例展示 Markdown、大纲、任务、双链/反链/嵌入、搜索和模板。导入后的范例与普通笔记相同，可以编辑或删除；再次导入只补缺失标题，不覆盖同名笔记。

## 开发者直接注入 / 清理

以下脚本会直接操作本机测试数据，只用于开发走查；产品内请使用“导入功能范例”。

```bash
# 1. 先退出应用（./sophonote.sh stop 或 ⌘Q）
bash scripts/walkthrough-samples/inject.sh
# 2. 启动应用 → 笔记本出现 6 篇「样例」开头的笔记
# 3. 走查完清理（先退出应用）：
bash scripts/walkthrough-samples/inject.sh --remove
```

## 逐项走查小抄

### B4 大纲（样例·深度学习研读）
1. 打开该笔记，状态栏点「大纲」打开大纲面板；
2. 点大纲里的「四、工程落地要点」→ 正文平滑滚到该节；
3. 从头慢慢往下滚 → 大纲高亮项跟随；
4. 检查大纲里**没有**「核心观点」（那是底部 `![[嵌入]]` 卡片里的标题，不应串入本文大纲）。

### B5 Tasks 回链（样例·任务清单）
1. 侧栏「任务」页 → 找到「样例·任务清单」分组；
2. 勾选第一条任务 → 回到该笔记看这条已变已勾选（真实写回 .md）；
3. 点任务标题 → 跳回笔记并滚动定位到对应行；
4. 已完成的那条显示删除线。

### B6 改名双链同步（靶子 = 样例·被引用页）
1. 笔记本列表右键「样例·被引用页」→ 行内改名为「样例·被引用页·改」回车；
2. 打开「样例·双链引用页」：三种形态（标准/别名/标题链接）全部跟随新名；
3. 该页反链面板：引用计数仍在，「提及未链接」里的裸提及也变成新名。

### B7 模板（样例模板·会议纪要）
1. 笔记本「新建」按钮右侧 ▾ → 下拉里出现「样例模板·会议纪要」；
2. 点它新建 → `{{title}}/{{date}}/{{time}}` 被替换为真实值；
3. 新笔记不带 `#template` 标签（不会自己变成模板）；
4. 走查完可删掉新建的这篇。

### B8 搜索（关键词 = 飞轮效应）
1. ⌘K 搜「飞轮效应」→ 命中 3 篇样例（搜索陪练 3 处、深度学习研读 1 处、双链引用页 1 处），有命中片段 + 高亮 + 「N 处命中」；
2. 笔记本列表搜索框搜同词 → 卡片显示命中片段行与计数；
3. 深色模式下高亮仍可读（可切深色看一眼）。

### B9 悬停预览卡（样例·双链引用页）
1. 该笔记切**预览**模式；
2. 鼠标悬停「[[样例·被引用页]]」约 0.3 秒 → 弹出预览卡；
3. 鼠标移入卡内滚动 → 卡片不消失；
4. 链接在窗口下半部时卡片向上弹；点卡内「打开」跳转；
5. 悬停一个不存在的链接（可在编辑态临时写 `[[不存在的笔记]]` 再预览）→ 显示「点击链接即可创建」。

### B10 别名 / 标题链接 / 段落嵌入（样例·双链引用页 + 样例·深度学习研读）
1. 双链引用页预览态：「点我看别名形态」只显示别名、点击跳被引用页；「[[样例·被引用页#核心观点]]」点击后滚动定位到「核心观点」段；
2. 深度学习研读底部有 `![[样例·被引用页#核心观点]]` 段落嵌入卡——只截「核心观点」到下一同级标题之间的内容；
3. 在嵌入卡里勾选「B10 嵌入写回自测」→ 回被引用页看该行已勾选（写回源文档正确行）；
4. 右键被引用页改名 → 三种形态（标准/别名/标题链接/嵌入）全部跟随不断链（与 B6 同场验）。

## 注意

- 样例注入的是真实数据目录：`~/Library/Application Support/com.fei.sophonote`（notes/ + sophonote.db articles 表 `sample-*` 行）；
- B6 改名后若想恢复原样：直接 `--remove` 再重新注入即可（改名产生的双链改写发生在样例内部，不影响你自己的笔记）；
- 样例笔记不参与项目归属、不会出现在 AI 工作室候选之外的任何自动流程里。
